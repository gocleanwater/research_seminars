# 이 논문 작업 재개

다른 공부 채팅에 다음처럼 말하면 된다.

```text
이 폴더의 START_HERE.md와 AGENTS.md부터 읽고 공부와 HTML 발표 제작을 이어가자.
docs/SEMINAR_PLAYBOOK.md와 docs/FEEDBACK_LESSONS.md의 좋은 예문/재발 방지 기준,
PROJECT.md·OUTLINE.md·review/PROGRESS.md·review/FEEDBACK.md에서 현재 상태를 확인해.

Section을 마칠 때마다 실제 공부 내용을 MD로 정리해.
발표는 대본 흐름을 먼저 자연스럽게 만든 뒤 같은 순서로 화면·그림을 구성해.
sections/*.md를 수정하고 build → check → verify로 생성·검증해.
대본을 직접 수정한 내용도 Section 원본에 먼저 반영해 덮어쓰지 마.
수정 요청과 좋았다는 평가를 모두 기록하고 다음 수정에서 먼저 읽어.
자동 검사와 원문/의미/중복 검토를 구별해. 공개는 별도로 결정하자.
```

논문 원문과 중앙 공부 기록 경로는 PROJECT.md에 연결한다. 초기 `00-start.md`는 실행 확인 예시이며 실제 논문 내용이 아니다. 새로운 논문은 빈 틀에서 시작하고, 이미 제작된 발표는 이 템플릿으로 덮어쓰지 않는다.
