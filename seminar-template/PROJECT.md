# 프로젝트 연결

- 논문명: seminar.json과 함께 지정
- 원문 파일/URL:
- 공부 기록: 기본 study/, 중앙 위키를 쓰면 seminar.json의 study_dir과 함께 수정
- 현재 단계: scaffold / 공부 / 목차 / 초안 / 수정 / 검토
- 발표 편집 원본: sections/*.md
- 화면·대본 생성: python3 scripts/seminar.py build
- 검사: check → pnpm verify → 원문/흐름/중복 검토
- 시간/청중: 사용자가 정하면 기록, 비어 있다고 제작을 막지 않음
- 공개 상태/권한: 아직 없음. 다른 논문의 push/배포 권한을 상속하지 않음.
