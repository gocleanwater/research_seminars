# 장별 검토 — 자동 검증과 별개

- 대상 ID / 현재 Section 공부 기록:
- 유지할 기존 흐름과 사용자가 좋다고 한 문장:
- 직전 장에서 이어지는 한 문장:
- 이번 화면이 답하는 질문 / 새 정보:
- 대본 순서와 그림의 보는 순서:
- 기존/개선 비교 항목과 화살표의 실제 의미:
- 수식: 방법 정체 → 식의 역할 → 기호 → 의미:
- 원문 표/단위/대표 비교/저자 해석 구분:
- 삭제한 불필요한 발화 / 보존한 필수 지표 조건:
- 다음 화면과의 중복 / 자연스러운 전환:
- 실제 브라우저 검사 결과와 미확인 사항:
- 사용자 피드백 원문 / 반영 위치 / 미반영 이유:

좋았다는 특정 문장 평가를 전체 발표 승인으로 바꾸지 않는다. 자동 검사로 의미·원문 사실 검증을 대신하지 않는다.
