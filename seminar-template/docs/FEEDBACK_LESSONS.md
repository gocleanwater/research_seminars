## RLDX-1에만 남길 결정

- Fig.1 표지, Fig.2→Fig.3, Vision Encoder/VLM/Memory/MSAT의 구체적인 확대 상태와 화살표 수는 RLDX-1 구성이다. 다른 논문에 강제하지 않는다.
- h_t/m_t concat, 중간층/64 cognition tokens, text critic, Action/Physics 경로의 학술적 내용은 해당 원문 근거로 설명한다. 다른 모델에 그대로 적용하지 않는다.
- 실험 부록 제외, 실제 Fused Kernels 페이지 제외, 특정 장을 대본으로 통합한 결정은 현재 RLDX-1 발표 범위다. 다른 논문의 부록·실험을 자동으로 삭제하지 않는다.
- Gravity/GitHub 중심과 U-Net 보조라는 참고 우선순위는 그 제작 당시의 선택이다. 새 작업에서 참고 자료가 달라지면 새 지시를 따른다.
- 기존 자동 commit/push 지시는 그 프로젝트의 이력이다. 이번 하네스 정리나 다음 논문 전체의 게시 권한이라고 확대하지 않는다.
