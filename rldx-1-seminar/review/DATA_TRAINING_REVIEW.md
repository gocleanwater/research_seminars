# v35 — 학습 데이터와 학습 단계의 설명 흐름

2026-11-18. 사용자 요청으로 전체 구조를 수정했고, 개별 결과물은 검토 전이다.

## 범위와 원문 근거

데이터의 역할과 합성 파이프라인은 Sec.3–3.3(PDF pp.9–12), 세 학습 단계는 Sec.4–4.3(pp.12–15), RECAP 반복은 App.C Algorithm 1(p.43)을 확인했다. Public/In-house는 소개에만 두고 Synthetic을 자세히 설명한다. 학습 단계의 비중은 사용자 답변에 따라 Pre/Mid/Post 모두 각각 목적과 흐름을 다룬다.

- 공개 실제 데이터: 다양한 몸체의 action prior, 즉 조작의 기본기.
- 자체 실제 데이터: ALLEX/Franka 특화와 기억·토크·촉각 등 새 기능의 지도 신호.
- 합성 데이터: Task/Scene 다양성을 늘려 직접 수집하기 어려운 경험을 보완. 합성 GR-1은 Pre-training, ALLEX 합성은 Mid-training에도 사용한다.
- Task-specific post-training은 학습 목적이다. Synthetic이라는 데이터 생성 방식과 일대일로 대응하지 않는다.
