## 적용 제안 — 사용자 승인된 디자인으로 간주하지 않음

1. 승인된 12부 목차와 후보 설명 단위는 유지한다. 참고자료의 20분·본편 장수 제한을 가져오지 않는다.
2. 기본 테마는 밝은 바탕·짙은 남색 글자·제한된 강조색을 제안한다. 표지·장 구분에는 더 강한 색면을 사용할 수 있다. 최종 색상은 S001 실제 화면으로 검토한다.
3. 큰 구조 → 익숙한 상황 → 단순 도식 → 원문 그림·수식 → 예시 → 전체 구조 재확인의 순서를 내용에 맞게 사용한다. 모든 장을 동일한 박스 배치로 강제하지 않는다.
4. Flow matching: 점 하나의 숫자 예시에서 시작해 노이즈·정답·예측 변화율·denoising timestep 간격을 대응시키고 action chunk로 확장한다. 설명용 수치를 원문 실험값과 구분한다.
5. MSAT: C 토큰 4개와 A 토큰 3개 예시로 joint attention의 정보 교환·query별 출력·stream별 residual을 차례로 보여준다. 후반 C/A concat은 별도 단계로 표시하고 정보 교환과 토큰 연결을 혼동하지 않는다.
6. Memory: 과거 관측에서 현재 행동까지 시간축으로 그린다. 저장 간격과 정확한 queue 갱신·초기화 중 원문으로 확인되지 않은 부분은 예시로 단정하지 않는다.
7. 실험: task·측정 기준·비교 조건 → 원문 그래프나 정확한 수치의 차트 → 관찰·한계 순서. Chart.js는 필요할 때만 사용하며 원문 이미지와 숫자의 출처를 남긴다.
8. 원문 이미지와 직접 만든 설명 그림을 병행하고, 색상만으로 의미를 구분하지 않는다. 사실·해석·미해결은 필요한 부분에 짧은 문자 표지로 표시한다.
