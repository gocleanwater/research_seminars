# RLDX-1 전체 HTML 초안 제작 계획

**Goal:** 승인된 설명 내용을 관련 단위끼리 묶어 본문30장과 연결 상세 해설로 만들고, 이후 한 장씩 수정할 수 있도록 근거·검토 상태를 기록한다.
**Architecture:** 범위별 JSON 콘텐츠를 단일 생성기로 Slidev slides.md와 오프라인 presentation.html로 변환한다. 원문 그림을 필요한 부분만 추출하고 공통 CSS·출처·장 ID를 공유한다.
**Tech Stack:** 기존 Slidev/Vue, Python PDF 추출, HTML/CSS/JavaScript, Playwright/Chrome.
**Spec:** OUTLINE.md, PROJECT.md, review/REFERENCE_REVIEW.md, docs/content-contract.md, 2026-11-05 전체 제작 후 한 장씩 수정하라는 사용자 지시.
