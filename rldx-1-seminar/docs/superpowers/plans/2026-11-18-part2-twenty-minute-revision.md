# Part 2 대본 중심 수정과 20분 분량

사용자 요청: 6·7쪽은 제시한 인과 설명을 자연스럽게 다듬고 그 대본을 화면으로 표현. 그 외 1–8쪽은 유지. 이후 실험 소개가 지나치게 긴 문제를 줄이되 핵심 결과를 보존.

1. P020을 입력 구성→고정 배포·준비값 재사용 한 화면, Figure9 실행 비교 한 화면으로 구성. P038은 Figure10 좌/우를 각각 크게 읽으며 설명. 새 정보 없이 같은 내용을 반복하는 단계를 만들지 않음.
2. 과제 소개·결과를 OpenArm/ALLEX/Franka별 한 장으로 합침. VLM 두 표, 합성 규모, RL, 추론 최적화는 비교 조건 한두 줄과 결과를 같은 장에 배치. 독립 설정 강의9장 통합. Table1 전체값 유지.
3. 기존121개 원본 공부 기록을 그대로 옮기며 ID alias·목차·전체/Part2 대본을 맞춤. Part1과 Part2의1–5·8쪽은 내용 유지.
4. 20분 진행표를 발표자용 기록으로 작성. 화면 낭독식 수치 나열보다 비교→대표 결과→의미를 짧게 말함. 과장·지표 혼동 방지에 필요한 조건은 유지.
5. 소스·대본·단위 보존·보호 구간 비교·전체 렌더·새 화면 동작·기존 탐색·표 수치 확인 후 커밋·push.

작업 선택: 모든 설정 장을 남기고 말만 줄이면 페이지 전환·중복 소개가 남으므로, 설정과 결과를 합쳐 설명 맥락을 유지한다. 사용자에게 장수 자체를 목표로 제시하지 않으며, 분량은 실제 리허설로 조정한다.
