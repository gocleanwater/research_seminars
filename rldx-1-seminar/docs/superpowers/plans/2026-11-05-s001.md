# S001 표지 제작 계획

**Goal:** 승인된 목차의 S001 한 장을 실제 Slidev HTML과 PNG로 제작한다.
**Architecture:** 기존 Slidev 설정을 유지하고 slides.md를 한 장의 표지로 교체한다. style.css에 표지 스타일을 추가하며 이미지 한 개를 PDF에서 추출한다.
**Tech Stack:** Slidev 53, Vue, CSS, pypdf, Playwright/Chrome.
**Spec:** PROJECT.md, OUTLINE.md, review/REFERENCE_REVIEW.md 및 사용자의 "이제 한 번 만들어보자!" 요청.

## 범위와 검토

- S001만 제작하며 사용자 승인 전에 S002로 넘어가지 않는다.
- 큰 제목, 밝은 배경, 남색 글자와 제한된 강조색, 충분한 여백으로 구성한다.
- 원문 p.1·Abstract p.3에서 연구 주제를 확인하고 Fig.12(b) p.19의 ALLEX 이미지를 사용한다.
- 발표자 신상·발표일은 이전 발표에서 가져오거나 추정하지 않는다.
- 이미지 비율·투명도·출처, 한글, 화면 경계, 파일 경로와 base 빌드를 확인한다.
- 외부 공개·GitHub 작업 없음. 승인 기록을 만들지 않는다.
