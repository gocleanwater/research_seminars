## P032 v05 반영 계획 — 진행 중

1. VLM 토큰 구간 video·language·cognition(64)을 그림에 직접 묶음 괄호(underbrace)와 화살표로 표시한다. 사용자의 추가 주석 참조 그림을 배치 참고로 사용한다.
2. 과거 프레임 → context token 1개에 ‘압축’을 명시한다.
3. 본문은 ‘중간층’과 ‘cognition token 위치의 출력 특징을 행동 생성을 위해 전달’로 설명하고, 구체적인 18층 사실은 N 상세 해설에 보존한다.
4. 전체 그림 → 확대 → 주석 → 전체 복귀를 Memory Module까지 확장한다. Memory는 최신 정정에 따라 `C = concat(h_t, m_t)`로 토큰 축 연결을 표시한다.
5. 같은 확대·화살표 설명을 MSAT까지 확장한다. MSAT의 velocity 예측은 반복 denoising 후의 최종 clean action chunk와 구분한다.

버튼·좌우 방향키와 기존 PPT 조작을 유지하며 설명에 필요한 페이지·단계를 제한하지 않는다. 실제 구현·화면 검증 완료 및 사용자 승인은 별도 기록한다.

## 구성 방향

논문의 흐름을 따라가되, 함께 공부하며 필요했던 배경 개념·수식 풀이·벡터 예시를 해당 내용 앞에 배치한다. 원문 설명, 직관적인 예시, 실험 조건과 결과, 우리의 해석, 미해결 질문을 모두 다룬다. 아래 S 항목은 상세 설명 단위다. 최신 지시에 따라 관련 단위를 묶어 본문 30장으로 통합하고, 공부한 세부 내용은 해당 장의 N 상세 해설에 보존한다.

- 기본 순서: 문제 → VLM·시간 정보 → flow matching → MSAT → 데이터 → 학습 → 실행 최적화 → 평가 → ablation → 부록 → 연구 위치·미해결 질문.
- 표지 이외에도 하나의 장에서 설명할 핵심 질문을 정한다. 그림·표를 과도하게 축소하지 않고 필요한 구간·수식·실험을 나눠 해석한다.
- 원문의 사실과 실험 결과는 Section/Figure/Table/Equation 및 PDF 쪽수로 표시한다. 배경 설명·설명용 숫자·튜터의 해석은 원문 실험 사실과 구분한다.
- 미해결 질문은 관련 장에 함께 표시하고 마지막에도 모은다. 문서의 모호함을 확인되지 않은 모델 결함으로 바꾸지 않는다.
- tau는 denoising timestep이라고 부른다. 실제 로봇 시점 t와 구분한다. 로봇 이름은 OpenArm·ALLEX·Franka를 사용한다.
- 평가에서 성공률/부분점수, p50/전체 제어 지연, 누적/증분 speedup, 합성 pool 크기/sampling 비중을 구분한다.
- 본문 30장 전체 초안과 121개 연결 상세 해설을 제작했다. 전체 제작 허가는 개별 결과물 승인이 아니다.
